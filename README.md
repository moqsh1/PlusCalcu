# PlusCalcu

A beautiful, modern calculator web application.

## Features

- Clean glassmorphism design
- Full calculator functionality (+, −, ×, ÷)
- Percentage support
- Keyboard support
- Responsive design
- Error handling for division by zero

## How to Use

Simply open `index.html` in any modern web browser.

## Keyboard Shortcuts

- Numbers and decimal point
- `+`, `-`, `*`, `/` for operations
- `Enter` or `=` to calculate
- `Escape` to clear
- `Backspace` to delete
